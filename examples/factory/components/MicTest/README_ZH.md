# Mic Test

[English](README.md) | [简体中文](README_ZH.md)

## 功能

分别显示 MIC1/MIC2 音量条，同时录制两个麦克风最多 5 秒，并通过扬声器单独回放各通道。

## 硬件需求

ESP32-S3-Touch-LCD-1.85B 和接好的扬声器。无需 SD 卡。

## 怎么运行

安装[出厂应用](../../README_ZH.md)，退出其他音频应用后打开 Mic Test。点击 Record，依次靠近两个麦克风说话，需要提前结束时点击 Stop。

## 预期现象

两个音量条随声音变化，MIC1、MIC2 按钮分别回放对应录音。回放音量使用 Settings 中的设置；重新录音会覆盖上一段，关闭应用后录音不再保留。

## 常见问题

dBFS 表示数字录音电平，不是经过标定的声压值；CLIPPED 表示采样接近数字满幅。本测试检查未经过回声消除或降噪的原始麦克风声音，两个麦克风同时收到声音属于正常现象。
