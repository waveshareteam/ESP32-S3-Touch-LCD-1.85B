# AIChats

[English](README.md) | [简体中文](README_ZH.md)

## Function

Voice conversation with on-screen expressions and text. Say "你好小智" to wake the assistant, or say it during a reply to interrupt and start a new turn.

## Hardware

ESP32-S3-Touch-LCD-1.85B with its dual microphones and a connected speaker. A working 2.4 GHz Wi-Fi connection and access to the voice service are required.

## Run

Install the complete [factory application](../../README.md), connect Wi-Fi in Settings, and open AIChats. On first use, follow the activation instructions and bind the code shown on screen.

## Expected behavior

After connecting, say "你好小智" or tap Talk to start; tap Stop to end the current turn. The screen shows connection status and conversation text, and voice commands can adjust volume and brightness.

## FAQ

Exit Music or Mic Test before opening AIChats. Install the complete factory firmware so the wake-word model is included; long replies and activation instructions can be scrolled.
