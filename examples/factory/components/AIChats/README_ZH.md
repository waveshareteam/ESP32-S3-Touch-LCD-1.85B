# AIChats

[English](README.md) | [简体中文](README_ZH.md)

## 功能

通过语音进行对话，并在屏幕显示表情和文字。说“你好小智”唤醒，也可在回复过程中说唤醒词打断并开始新一轮对话。

## 硬件需求

ESP32-S3-Touch-LCD-1.85B 的双麦克风及接好的扬声器。需要可正常联网的 2.4GHz Wi-Fi，并能够访问语音服务。

## 怎么运行

安装完整的[出厂应用](../../README_ZH.md)，在 Settings 中连接 Wi-Fi，再打开 AIChats。首次使用请根据屏幕提示完成激活和绑定。

## 预期现象

连接成功后，说“你好小智”或点击 Talk 开始，点击 Stop 结束当前轮次。界面显示连接状态和对话文字，也可通过语音调节音量及屏幕亮度。

## 常见问题

打开 AIChats 前，请先退出 Music 或 Mic Test。首次安装应烧录完整出厂固件，以包含唤醒词模型；长回复及激活说明可以滚动查看。
